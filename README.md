# @tuanla90 NocoBase Plugins — Free Edition

> **6 free, production-grade plugins for NocoBase 2.x** — install in one minute, no upload, no sign-up.
> A taste of the full 47-plugin suite.

**Tiếng Việt bên dưới · English first · 简体中文说明在各插件内置**

## Quick install (1 minute)

1. NocoBase admin → **Plugin manager → Add → URL** → paste:
   ```
   https://raw.githubusercontent.com/tuanla90/nocobase-plugin-public/main/latest/@tuanla90/plugin-hub-0.2.1.tgz
   ```
   → Install → **Enable**.
2. Open **Settings → Plugin Hub** → **Check now** → install anything below with one click.

Per-plugin URLs and the Railway/Docker volume note: see [INSTALL.md](INSTALL.md).

## What's in the free edition

| Plugin | What it does |
|---|---|
| **Plugin Hub** | Installs & updates every plugin here from one screen — weekly update check (notify-only). |
| **App Doctor** | Health check for your app: finds broken/one-sided relations (one-click repair) **and** performance weak spots — row volume, missing foreign-key indexes (one-click `CREATE INDEX`), oversized pages — plus a real probe that times a table's `COUNT(*)` and page fetch separately. |
| **Crash Guard (stability)** | Stops a malformed relation from white-screening the modern (/v/) client, and caps keep-alive DOM bloat. |
| **Field Order** | Drag-and-drop the display order of a collection's fields — works on both UIs. |
| **Column Resize** | Persistent, draggable column widths for tables. |
| **Custom Icons** | 1,700+ Lucide icons available everywhere NocoBase shows an icon picker. |

All plugins: **English / Tiếng Việt / 简体中文**, classic `/admin` **and** modern `/v/` clients, NocoBase ≥ 2.x.

## The full suite (47 plugins)

# Bản tiếng Việt

> **6 plugin miễn phí, chất lượng production cho NocoBase 2.x** — cài trong một phút, không cần upload,
> không cần đăng ký. Một lát cắt của bộ đầy đủ 47 plugin.

## Cài nhanh (1 phút)

1. Admin NocoBase → **Plugin manager → Add → URL** → dán:
   ```
   https://raw.githubusercontent.com/tuanla90/nocobase-plugin-public/main/latest/@tuanla90/plugin-hub-0.2.1.tgz
   ```
   → Install → **Enable**.
2. Vào **Cài đặt → Plugin Hub** → **Kiểm tra ngay** → cài mọi thứ bên dưới bằng một cú bấm.

URL từng plugin và lưu ý volume Railway/Docker: xem [INSTALL.md](INSTALL.md).

## Có gì trong bản miễn phí

| Plugin | Nó làm gì |
|---|---|
| **Plugin Hub** | Cài & cập nhật mọi plugin ở đây từ một màn hình — kiểm tra cập nhật hàng tuần (chỉ báo). |
| **App Doctor** | Khám sức khoẻ app: tìm quan hệ hỏng/một chiều (sửa 1 chạm) **và** điểm yếu hiệu năng — khối lượng dòng, khoá ngoại thiếu index (tạo index 1 chạm), trang quá lớn — kèm đo thật: tách thời gian `COUNT(*)` và thời gian lấy trang. |
| **Chống treo (ổn định)** | Chặn quan hệ hỏng làm trắng màn hình client /v/, và giới hạn DOM phình do keep-alive. |
| **Field Order** | Kéo-thả thứ tự hiển thị field của một bảng — chạy trên cả hai giao diện. |
| **Column Resize** | Kéo chỉnh và lưu bề rộng cột bảng. |
| **Custom Icons** | 1.700+ icon Lucide dùng được ở mọi chỗ NocoBase cho chọn icon. |

Tất cả plugin: **English / Tiếng Việt / 简体中文**, chạy trên cả `/admin` cổ điển **và** `/v/` hiện đại, NocoBase ≥ 2.x.
